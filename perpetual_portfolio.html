Cloud Sync

Syncs through a secret GitHub gist using your classic token (scope: gist). The app only ever touches the single gist ID stored on this device — it never lists or scans your other gists, and it never creates anything without asking.

Not connected

First device: enter your token, leave the gist ID blank, tap Save & Connect, and confirm "Create a NEW cloud store". Tap Copy to get the ID.

Every other device: paste that gist ID (or its URL), add the same token, tap Save & Connect. The ID is verified against GitHub before it's saved.

Token safety: a classic gist token can read and write all your gists, so treat it like a password — it's stored only in each browser's own storage. If a device is lost, revoke the token at github.com/settings/tokens and create a new one. Nothing syncs until both a token and a gist ID are set on the device.

Conflicts: last-write-wins by timestamp — don't edit on two devices at once, and use Export for a hard backup before big editing sessions.
